# SportLog

SwiftUI-приложение для движения, питания и ежедневного режима. Тёмные экраны с карточками и нижними вкладками: главная, статистика, рецепты и меню.

## Возможности

- Приветствие по времени суток, сводка шагов, активной энергии, сна и тренировок за сегодня.
- Apple Health: чтение данных по запросу пользователя, график шагов за последние семь дней. Отсутствие данных не подменяется демонстрационными значениями.
- Карта GPS-маршрутов тренировок из Health за последние 30 дней (до 50 последних тренировок). Общий счётчик шагов не содержит координат; обычные шаги без записанной GPS-тренировки нанести на карту нельзя. Фоновая геолокация не используется.
- Три настраиваемых ежедневных локальных напоминания: еда, тренировка, сон. После изменения часов нажмите «Сохранить расписание».
- Восемь рецептов с локальными фотографиями, ингредиентами, инструкциями, поиском, избранным, фильтрами категории, приёма пищи и калорийности.
- Метод ладони: приблизительная оценка основных макронутриентов на приём пищи, без сопутствующих нутриентов.
- Календарь с локальными заметками до 31 декабря 2028 года, видеотренировки и музыкальные ссылки.

## Запуск и HealthKit

Откройте `SportLog.xcodeproj` в Xcode 27.2, выберите iPhone и запустите приложение. Проект использует новый формат `project.xcproj` — переименовывать его в `project.pbxproj` не нужно.

Для установки на физический iPhone выберите свою команду подписи и включите HealthKit для App ID в Apple Developer. Entitlements и описание причины чтения уже добавлены. На главной нажмите «Подключить / обновить Apple Health», разрешите нужные категории. Чтение отдельных категорий можно отключить в Здоровье; API Apple не сообщает приложению, отличается ли отказ от отсутствия записей.

Маршрут должен быть заранее записан совместимым приложением/Apple Watch. Реальные данные Health, разрешения и доставку уведомлений проверяйте на iPhone: успешная сборка симулятора не подтверждает работу учётной записи и профиля подписи.

## Приватность

Данные Health обрабатываются на устройстве и не отправляются на сервер SportLog. Заметки, порции и избранное сохраняются локально. Фото рецептов включены в сборку; YouTube, Spotify и Яндекс Музыка открываются внешними ссылками. Карта использует Apple MapKit.
