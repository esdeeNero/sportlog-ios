# SportLog

Простой iPhone-трекер спортивных занятий на SwiftUI. На главном экране отображаются недельная цель, дни недели и план тренировок. Нажатие на занятие отмечает его выполненным и обновляет прогресс.

## Запуск

Открой `SportLog.xcodeproj` в Xcode, выбери симулятор iPhone и нажми Run.

## Git

Каждый законченный этап сохраняй через Source Control → Commit, затем отправляй на GitHub через Source Control → Push.
